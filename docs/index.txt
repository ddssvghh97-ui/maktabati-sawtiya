var CRC=(function(){var t=new Uint32Array(256);for(var n=0;n<256;n++){var c=n;for(var k=0;k<8;k++)c=c&1?0xEDB88320^(c>>>1):c>>>1;t[n]=c>>>0;}return t;})();

async function makeZip(entries){
  var enc=new TextEncoder(),parts=[],central=[],offset=0;
  for(var i=0;i<entries.length;i++){
    var e=entries[i],data=new Uint8Array(await e.blob.arrayBuffer()),nameB=enc.encode(e.name),crc=crc32(data);
    var d=new Date(e.date||Date.now());
    var time=(d.getHours()<<11)|(d.getMinutes()<<5)|(d.getSeconds()>>1);
    var day=(Math.max(0,d.getFullYear()-1980)<<9)|((d.getMonth()+1)<<5)|d.getDate();
    var lh=new DataView(new ArrayBuffer(30));
    lh.setUint32(0,0x04034b50,true);lh.setUint16(4,20,true);lh.setUint16(6,0x0800,true);lh.setUint16(8,0,true);
    lh.setUint16(10,time,true);lh.setUint16(12,day,true);lh.setUint32(14,crc,true);
    lh.setUint32(18,data.length,true);lh.setUint32(22,data.length,true);lh.setUint16(26,nameB.length,true);lh.setUint16(28,0,true);
    parts.push(lh.buffer,nameB,data);
    var ch=new DataView(new ArrayBuffer(46));
    ch.setUint32(0,0x02014b50,true);ch.setUint16(4,20,true);ch.setUint16(6,20,true);ch.setUint16(8,0x0800,true);ch.setUint16(10,0,true);
    ch.setUint16(12,time,true);ch.setUint16(14,day,true);ch.setUint32(16,crc,true);
    ch.setUint32(20,data.length,true);ch.setUint32(24,data.length,true);ch.setUint16(28,nameB.length,true);
    ch.setUint32(42,offset,true);
    central.push(ch.buffer,nameB);
    offset+=30+nameB.length+data.length;
  }
  var cdSize=0;central.forEach(function(c){cdSize+=c.byteLength;});
  var eo=new DataView(new ArrayBuffer(22));
  eo.setUint32(0,0x06054b50,true);eo.setUint16(8,entries.length,true);eo.setUint16(10,entries.length,true);
  eo.setUint32(12,cdSize,true);eo.setUint32(16,offset,true);
  return new Blob(parts.concat(central,[eo.buffer]),{type:'application/zip'});
}

function drawWave(c,it,ratio){
  var box=c.querySelector('.wave'),cv=box.firstElementChild,w=box.clientWidth,h=box.clientHeight;
  if(!w||!h)return;
  var dpr=window.devicePixelRatio||1,W=Math.round(w*dpr),H=Math.round(h*dpr);
  if(cv.width!==W||cv.height!==H){cv.width=W;cv.height=H;}
  var g=cv.getContext('2d');g.setTransform(dpr,0,0,dpr,0,0);g.clearRect(0,0,w,h);
  var col=cat(it.category).color,x=ratio*w,pk=peaksOf(it);
  if(!pk||!pk.length){
    g.fillStyle=WAVE_OFF;g.fillRect(8,h/2-2,w-16,4);
    g.fillStyle=col;g.fillRect(8,h/2-2,Math.max(0,(w-16)*ratio),4);return;
  }
  var bw=3,gap=2,n=Math.max(8,Math.floor((w-8+gap)/(bw+gap))),len=pk.length,ox=(w-(n*(bw+gap)-gap))/2;
  for(var i=0;i<n;i++){
    var a=Math.floor(i*len/n),b=Math.max(a+1,Math.floor((i+1)*len/n)),m=0;
    for(var j=a;j<b&&j<len;j++)if(pk[j]>m)m=pk[j];
    var bh=Math.max(3,(m/100)*(h-10)),bx=ox+i*(bw+gap);
    g.fillStyle=(bx+bw/2)<=x?col:WAVE_OFF;
    g.beginPath();
    if(g.roundRect)g.roundRect(bx,(h-bh)/2,bw,bh,1.5);else g.rect(bx,(h-bh)/2,bw,bh);
    g.fill();
  }
}

function filtered(){
  var q=norm(S.q.trim());
  var list=S.items.filter(function(it){
    if(S.cat==='fav'){if(!S.favs.has(it.id))return false;}
    else if(S.cat!=='all'&&it.category!==S.cat)return false;
    if(S.fmt!=='all'&&it.ext!==S.fmt)return false;
    if(S.lic==='free'&&needsCredit(it))return false;
    if(S.lic==='by'&&!needsCredit(it))return false;
    if(q&&norm(it.name+' '+cat(it.category).label+' '+it.ext+' '+(it.author||'')+' '+(it.source||'')).indexOf(q)<0)return false;
    return true;
  });
  var cmp={
    'new':function(a,b){return (b.added||0)-(a.added||0);},
    'old':function(a,b){return (a.added||0)-(b.added||0);},
    'name':function(a,b){return a.name.localeCompare(b.name,'ar');},
    'long':function(a,b){return (b.duration||0)-(a.duration||0);},
    'short':function(a,b){return (a.duration||0)-(b.duration||0);}
  }[S.sort];
  return list.sort(cmp);
}

function metaDuration(f){
  return new Promise(function(res,rej){
    var a=new Audio(),u=URL.createObjectURL(f),done=false;
    function fin(ok,v){if(done)return;done=true;URL.revokeObjectURL(u);ok?res(v):rej(v);}
    a.preload='metadata';a.onloadedmetadata=function(){fin(true,a.duration);};a.onerror=function(){fin(false,new Error('meta'));};
    setTimeout(function(){fin(false,new Error('timeout'));},8000);a.src=u;
  });
}
function computePeaks(ab){
  var n=96,chs=ab.numberOfChannels,len=ab.length,peaks=new Array(n).fill(0),max=0;
  for(var c=0;c<chs;c++){
    var d=ab.getChannelData(c);
    for(var i=0;i<n;i++){
      var a=Math.floor(i*len/n),b=Math.floor((i+1)*len/n),step=Math.max(1,Math.floor((b-a)/400)),m=0;
      for(var j=a;j<b;j+=step){var v=Math.abs(d[j]);if(v>m)m=v;}
      if(m>peaks[i])peaks[i]=m;
    }
  }
  peaks.forEach(function(v){if(v>max)max=v;});
  if(!max)return peaks.map(function(){return 4;});
  return peaks.map(function(v){return Math.round(Math.sqrt(v/max)*100);});
}
async function analyze(p){
  try{
    var dur=0,peaks=null;
    if(p.file.size<=80*1048576){
      try{
        var buf=await p.file.arrayBuffer(),Ctx=window.OfflineAudioContext||window.webkitOfflineAudioContext,ctx=new Ctx(1,1,44100);
        var ab=await new Promise(function(res,rej){var r=ctx.decodeAudioData(buf,res,rej);if(r&&r.then)r.then(res,rej);});
        dur=ab.duration;peaks=computePeaks(ab);
      }catch(e){}
    }
    if(!dur)dur=await metaDuration(p.file);
    if(!dur||!isFinite(dur))throw new Error('bad');
    p.duration=dur;p.peaks=peaks;p.status='ready';
  }catch(e){p.status='error';}
  if(!p.removed)rowState(p);
}

}
